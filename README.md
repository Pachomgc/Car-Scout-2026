# Car Scout

Car Scout is a browser car management application built with Python, NiceGUI and SQLAlchemy.

## Features

- Add cars
- Browse cars
- Search cars
- View car details
- Edit cars
- Delete cars

## Technologies

- Python
- NiceGUI
- SQLAlchemy
- SQLite

## Project Structure

- ui/ → frontend pages
- services/ → business logic
- data_access/ → database access
- domain/ → models

## Installation

Install requirements:

pip install -r requirements.txt

Run the application:

python app.py
